# CICD-Testing: Портфолио болон Автоматжуулалтын Демо

Энэхүү төсөл нь орчин үеийн вэб хөгжүүлэлт болон **GitHub Actions**, **Jenkins** ашиглан CI/CD (Тасралтгүй интеграцчилал болон Тасралтгүй байршуулалт) хэрхэн ажилладагийг харуулах зорилготой компани вэб сайт юм.

## 🌐 Онцлог болон Боломжууд
- **Монгол хэл дээрх агуулга**: Бүх тайлбар болон UI элементүүд Монгол хэл дээр.
- **CI/CD зааварчилгаа**: Автоматжуулалтын процессын дэлгэрэнгүй тайлбарыг вэб дээрээс шууд үзэх боломжтой.
- **Гэрэлт/Харанхуй горим (Light/Dark Mode)**: Хэрэглэгчийн хүсэлтээр дэлгэцийн горимыг солих товчлуур.
- **Респонсив дизайн**: Гар утас болон компьютер дээр төгс харагдана.

---

## 🏗️ CI/CD Ерөнхий ойлголт
Энэхүү репозитори нь автоматжуулалтын ажлын урсгалыг турших талбар юм.

### 1. GitHub Actions (Автомат байршуулалт)
`main` салбар (branch) руу код орох бүрт автоматаар GitHub Pages руу байршуулахаар тохируулагдсан.
- **Ажлын урсгал (Workflow)**: `.github/workflows/deploy.yml`
- **Шаардлага**: GitHub репозиторийн тохиргоо (Settings > Actions) дээр **Read and Write permissions** эрх өгөгдсөн байх ёстой.

### 2. Jenkins (Автоматжуулалтын сервер)
Өөрийн сервер дээр CI/CD ажиллуулахад зориулсан `Jenkinsfile`-тай.
- **Шатлалууд (Stages)**: Checkout -> Install -> Build -> Deploy.
- **Хэрэгсэл**: Jenkins дээр Node.js 20+ хувилбар тохируулагдсан байх шаардлагатай.

---

## 🛠️ Локал орчинд ажиллуулах

1. **Сангуудыг суулгах:**
   ```bash
   npm install
   ```

2. **Хөгжүүлэлтийн сервер ажиллуулах:**
   ```bash
   npm run dev
   ```

3. **Байршуулах хувилбарыг бэлтгэх (Build):**
   ```bash
   npm run build
   ```
